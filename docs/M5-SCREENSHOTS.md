# M5 rendered-screen review inventory

These are actual Chromium captures of the React application and real NickHosting
handlers against isolated PostgreSQL/services and stateful external-provider
fixtures. Synthetic people, servers, evidence and `.example.test` addresses are
intentional test data; these screenshots are not live production observations.
Password/token fields are masked before capture. No generated mock screenshots,
proprietary game textures or production infrastructure notes are included.

The single supported light theme is represented at desktop 1440px and mobile
390px; a 320px expanded pseudolocale capture checks compact layout and keyboard
scrolling. Names specify locale and viewport. File input's native browser text
follows the browser/OS locale; application labels use the selected EN/IT catalog.

[Validation](M5-VALIDATION.md) records behavior, tests, independent review findings
and limitations. Screenshots supplement those tests; they do not prove API
success, real Minecraft support, complete WCAG conformance or SFTP SSH revocation.
The reverse Discord-to-email flow has browser behavior coverage; an incorrectly
placed duplicate image was excluded rather than presented as its visual evidence.
