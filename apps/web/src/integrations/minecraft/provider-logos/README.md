# Provider identification marks

These small, visually unmodified marks identify the corresponding catalog provider in the
Modpacks selector. They are served locally to avoid third-party requests from the
browser. Names and marks belong to their respective owners; inclusion does not
imply endorsement and does not relicense the marks as project source code.
